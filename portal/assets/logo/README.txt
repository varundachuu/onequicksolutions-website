Paste your logo file in this folder.

The login page will automatically show the first matching file it finds with one of these names:

portal-logo.svg
portal-logo.png
portal-logo.webp
portal-logo.jpg
portal-logo.jpeg

To show a second logo in the format:
logo 1 | logo 2

add one of these optional secondary files too:

portal-logo-secondary.svg
portal-logo-secondary.png
portal-logo-secondary.webp
portal-logo-secondary.jpg
portal-logo-secondary.jpeg

Recommended:
- Use portal-logo.png or portal-logo.svg
- Use portal-logo-secondary.png or portal-logo-secondary.svg for the second logo
- Keep the logo on a transparent background if possible
- A wide logo works best here
